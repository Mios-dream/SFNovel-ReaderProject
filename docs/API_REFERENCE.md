## 参数约定

- `{name}` 是路径参数；`查询` 是 URL query；`Body` 是 JSON；`Multipart` 是表单上传。
- 接口表中的 `deviceToken` 是服务端参数名，值仍使用 `deviceId`。
- `URL` 表示完整动态 URL 由调用方传入，表内路径 `{url}` 不是可拼接到 `API_BASE` 的固定路径。
- `expand` 是逗号分隔的扩展字段，例如有声章节：
  `fileName,audioUrl,needFireMoney,originNeedFireMoney,fileSize,duration`。
- `page` / `size` 是分页。有声已购链路实测从 `page=0` 开始；其他模块不要默认套用。
- `autoOrder` 控制自动购买，`orderAll` 控制整本购买，`chapIds` 是章节 ID 数组。
- `entityType` 在票券写入调用点可确认：`1=漫画`、`2=有声`；小说用独立接口。
- 接口声明没有 `@Nullable`，但服务端可能允许省略部分查询参数；以实测响应为准。

## 高频调用链

### 有声小说

```text
GET  /user/orderedalbums?page=0&size=50              已购/追更专辑
GET  /user/consumeitems?type=album&page=0&size=20    消费记录（补充已购专辑）
GET  /albums/{albumId}?expand=...                    专辑详情
GET  /albums/{albumId}/volumes                       分卷
GET  /albumvolumes/{volumeId}/chaps?expand=...       分卷章节列表（匿名）
GET  /albumchaps/{chapterId}?autoOrder=false         章节详情；需登录，data.fileName 才是 MP3
```

### 小说

```text
GET  /novels/{id}?expand=...                         详情
GET  /novels/{id}/dirs?expand=...                    目录
GET  /volumes/{id}/chaps?expand=...                  分卷章节
POST /novels/{id}/orderedchaps                       购买章节
```

购买请求体（阅读器调用点可确认）：

```json
{
  "chapIds": [123],
  "orderAll": false,
  "autoOrder": false,
  "orderType": "readOrder"
}
```

### 漫画

```text
GET  /comics/{id}?expand=...                         详情
GET  /comics/{id}/chaps?expand=...                   章节
GET  /comics/{id}/chappics/{pathName}?autoOrder=false 章节图片
GET  /user/orderedcomics?page=0&size=...             已购漫画
POST /comics/{id}/orderedchaps                       购买章节
```

### 搜索

```text
GET /search/all/result?q=关键词&expand=...&page=0&size=20
GET /search/novels/result?q=关键词&expand=...
GET /search/comics/result?q=关键词&expand=...&sort=...&page=0&size=20
GET /search/hotwords?searchtype=...&page=0&size=20
```

`q` 需要 URL 编码；`sort`/`expand` 的合法值从详情页调用点获取，不要猜。

### 评论、打赏、票券

```json
// 有声评论 POST /albums/{albumId}/albumcmts
{"content":"评论内容"}

// 有声/漫画/小说打赏
{"fireMoney":100,"cmtBody":"打赏留言"}

// 有声/漫画票券 POST /entity/{id}/tickets
{"num":1,"cmtBody":"月票留言","entityType":2}
```

字段来自 `com/sf/service/{c,p,w}.java`；其他写接口在反编译里只有 `Map<String,Object>`

## 覆盖范围与限制

- 覆盖 `com.sf.api` 下 16 个 Retrofit 接口类的全部声明。微信、阿里云 OSS/NLS、
  腾讯云 TTS、SignalR、广告/推送 SDK、CDN 的私有协议不在本文范围。
- 反编译只保留接口注解，不含服务端参数校验、枚举和响应 Schema；未给出 Body 字段的接口，
  必须结合真实调用点或抓包。
- `WeixinApi` 是相对路径，实际主机可能不是 `api.sfacg.com`，未实测前不要直接拼接。
- 作者端、支付、卡牌、抽奖、红包、删除等接口可能要求额外权限、实名、设备或验证码；
  接口存在不等于账号有权调用。
